# CSS Curriculum AI Transition Plan

Working documents for the UW Bothell Computing & Software Systems Department's multi-year curriculum change proposal. The goal is to equip CSSE and AC graduates with the skills needed in an AI-transformed job market.

Audience: CSS Faculty.

## Proposal Summary

**Phase 1 (2026-27):** Weave AI content into existing required courses (CSS 360, 211, 301, 350, 343); update capstone rubrics; pilot CSS 490 special topics; begin CSS 382 modernization; faculty AI bootcamp.

**Phase 2 (2027-28):** Launch new required course CSS 4xx (AI for Software Engineers); deploy modernized CSS 382; move CSS 370 from required to recommended elective to make room (Option C, pending faculty vote); phase out dormant catalog entries.

**Phase 3 (2028-29+):** AI present at every level from CSS 142 through capstone; two-course AI pathway established; goal-state degree maps for both CSSE and AC.

## Key Decisions Made

- AI fluency is a **core competency**, not an optional specialization
- Both CSS 382 (modernized, conceptual) and CSS 4xx (new, practical) are needed
- CSS 4xx will be a **required course** for CSSE and AC
- Changes apply to new incoming students; existing students may opt in by request

## Open Questions (faculty vote needed)

- Option C (CSS 370 → recommended) vs. alternatives for making room in the CSSE core
- AI teaching expertise of 4 new faculty starting September 2026
- Funding scenario: Moderate or Generous
- Curriculum AI Task Force volunteers (3-5 faculty)
